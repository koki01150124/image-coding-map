# order_004：論文収録範囲の網羅性監査

`image-coding-map`に収録されている論文・手法について，未収録の重要研究がないか体系的に調査してください．

## 調査方法

1. 既存44ノードのDOI・arXiv ID・正式タイトルを整理する
2. OpenAlex，Semantic Scholar，Crossref，arXivを横断検索する
3. 主要論文の参考文献と被引用論文を追跡する
4. 画像圧縮，LIC，SSCC，DeepJSCC，拡散型画像圧縮，ビット誤り耐性，パケット損失耐性を対象とする
5. 初出年と正式掲載年の違いを考慮して重複を排除する
6. 未収録論文を関連性・重要性・根拠の確実性で分類する

## 優先して確認する論文

- BitFlat（arXiv:2610.25682）
- DiffJSCC（arXiv:2404.17736）
- SGD-JSCC（arXiv:2501.01138）
- CDDM（DOI:10.1109/TWC.2024.3379244）
- ResiComp（DOI:10.1109/TCSVT.2025.3539747）
- Towards Loss-Resilient Image Coding for Unstable Satellite Networks（AAAI 2025）
- A Survey on Robust Deep Joint Source-Channel Coding（arXiv:2604.04413）

## 成果物

- 未収録論文の候補一覧（CSVまたはJSON）
- 検索式，検索日，検索対象，取得件数の記録
- 重複排除と採否判断の記録
- 追加優先度と理由
- 関連する既存ノードとの関係候補
- 網羅できていない分野の分析レポート

## 注意

論文が実在することと，既存手法から派生したことは区別してください．

論文間のエッジを追加する場合は，原論文の記述を根拠としてください．

今回の作業では，候補論文を無条件に本番データへ追加せず，監査結果を先に作成してください．

「全論文を網羅した」とは主張せず，定義した検索条件と対象期間に対する調査結果として報告してください．

## AIエディタによる解釈（作業開始時に追記）

- **タスクの種類**：文献調査（網羅性の監査）である．ai-survey-kit（`survey.md`）と `documentation.md` の規約を適用する．書誌情報は API の応答のみを用い，記憶から補わない．
- **本番データ**：`data/nodes/` と `site/` は変更しない．監査の成果物は `audit/` に置く．
- **検索の範囲**：OpenAlex，Semantic Scholar，arXiv の検索 API と，Crossref（DOI の解決）を用いる．検索式・検索日・対象・取得件数を `audit/search_log.json` に記録する．対象期間は原則 2015年〜2026年11月（従来型の符号化・通信路符号の基礎研究は期間を限定しない）とする．
- **スノーボーリング**：DeepJSCC（Bourtsoulatze），NECST，Scale Hyperprior，DDCM，Robust Turbo-DDCM，BlindSC，NTSCC の参考文献・被引用文献を OpenAlex で取得する．
- **重複排除**：DOI，arXiv ID，正規化したタイトルで照合し，プレプリントと正式掲載版を1件にまとめる．既存44ノードとも照合する．
- **候補の登録**：優先度の高い候補と order の優先確認論文のみ，`surveykit.py add` で `survey/library.json` に候補（candidate）として登録する．
- **評価**：関連性（対象分野・課題との関係），重要性（被引用数・掲載先・既存ノードとの関係），根拠の確実性（書誌情報の API での確認，内容は要旨のみか本文か）の3軸で分類し，追加の優先度（A／B／C）を付ける．既存ノードとの関係候補は要旨の記述を根拠とし，本文の確認が必要なものはその旨を明記する．派生関係は原論文に明示がある場合のみ候補とする．
- **報告**：定義した検索条件と期間に対する結果として報告し，網羅したとは主張しない．
